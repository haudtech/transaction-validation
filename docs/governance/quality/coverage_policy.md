## Coverage mindset

Coverage is not only a metric; it is a signal of risk reduction and confidence in changed behavior.

## Standard expectations

- unit coverage should cover business logic and validation behavior
- integration coverage should cover boundary behavior and host composition
- E2E coverage should cover deployed runtime confidence and user-level flow
- coverage should be reviewed when architecture or platform behavior changes
