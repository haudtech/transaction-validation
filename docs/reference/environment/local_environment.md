# Local Environment Reference

This document captures the local running assumptions for repository contributors.

## Typical local setup

- use the repo's pinned .NET SDK version
- start local infrastructure through the supported Docker or compose workflow
- keep environment-specific values outside the source tree
- prefer explicit environment variables over local hard-coded assumptions
